# AffinityAnswers Assignments

This repository contains the completed assignments for the AffinityAnswers recruitment process, unified into a single repository.

## Repository Structure

The repository is organized into the following directories:

*   **`screening_questions/`**: Contains the solutions for the first round (two screening questions).
    *   `parse_companies.sh`: Shell script for parsing companies.
    *   `scrape_mdcomputers.py`: Python script for scraping mdcomputers.
    *   `requirements.txt`: Python dependencies.
*   **`sql_challenge/`**: Contains the solutions for the second round (Rfam SQL challenge).
    *   `README.md`: Detailed explanation, verified answers, and instructions on how to run the queries.
    *   `question_a.sql`: SQL query for question A.
    *   `question_b.sql`: SQL query for question B.
    *   `question_c.sql`: SQL query for question C.

## Instructions

To evaluate the assignments, please navigate into the respective directories. Each directory contains the necessary code and instructions for that specific round.
